# Política de seguridad

## Aviso importante
Este repositorio contiene **código vulnerable a propósito** con fines didácticos
(`03-security/vulnerable_app.py`, `03-security/requirements-vulnerable.txt`). Todas las credenciales son ficticias.
**No lo uses en producción.** Las alertas de Dependabot / Code Scanning sobre esos archivos son esperadas.

## Reportar una vulnerabilidad real
Si encuentras un problema de seguridad que **no** sea una de las vulnerabilidades didácticas:
1. **No** abras un issue público.
2. Usa *Security → Report a vulnerability* (reporte privado de GitHub) en este repositorio.
3. Incluye pasos para reproducir y el impacto. Respondemos en un máximo de 7 días.

## Si encuentras un secreto real
Revócalo inmediatamente en el proveedor, avísanos por el canal privado y rota las credenciales. Borrar el commit no basta.

## Versiones soportadas
Solo la rama `main`.
