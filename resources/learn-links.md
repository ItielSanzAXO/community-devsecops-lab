# 📚 Recursos de aprendizaje

## 🌍 Comunidad
- [Microsoft Learn Student Hub](https://learn.microsoft.com/en-us/training/student-hub/) – rutas de aprendizaje y beneficios para estudiantes.
- [Microsoft Learn Student Ambassadors](https://studentambassadors.microsoft.com/) – programa global de líderes estudiantiles de tecnología.
- [GitHub Campus Experts](https://education.github.com/experts) – programa de liderazgo comunitario de GitHub para estudiantes.
- [GitHub Education](https://education.github.com/) – Student Developer Pack y herramientas gratuitas para estudiantes.

## 🤖 GitHub Copilot
- [GitHub Copilot Fundamentals (Microsoft Learn)](https://learn.microsoft.com/en-us/training/paths/copilot/) – ruta de aprendizaje.
- [Introduction to GitHub Copilot](https://learn.microsoft.com/en-us/training/modules/introduction-to-github-copilot/) – módulo introductorio.
- [Prompt Engineering con Copilot](https://docs.github.com/en/copilot/using-github-copilot/copilot-chat/prompt-engineering-for-copilot-chat) – guía oficial de prompts.
- [Documentación de GitHub Copilot](https://docs.github.com/en/copilot)

## 🛡️ DevSecOps
- [GitHub Actions](https://docs.github.com/en/actions) – automatización CI/CD.
- [GitHub Advanced Security](https://docs.github.com/en/code-security) – Secret Scanning, Code Scanning (CodeQL), Dependabot.
- [Microsoft Sentinel](https://learn.microsoft.com/en-us/azure/sentinel/overview) – SIEM/SOAR nativo en la nube.
- [Lenguaje KQL](https://learn.microsoft.com/en-us/kusto/query/) – consultas para Sentinel.
- [OWASP Top 10](https://owasp.org/www-project-top-ten/) – principales riesgos de seguridad en aplicaciones web.
